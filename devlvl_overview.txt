Devlvl - The Ultimate Gamified Coding Platform
==============================================

We have successfully transformed Devlvl from an idea into a fully-functional, gamified RPG coding platform.

Here is a complete breakdown of everything built:

1. The Core RPG Experience
---------------------------
- Onboarding: Choose an Avatar and a Developer Class (e.g., The Wizard, The Ninja).
- Dashboard: An RPG command center tracking Level, XP, DevCoins, and Daily Streaks.
- World Map: A zigzagging map (like Duolingo). Beat "Code Village" to unlock "Loop Forest".
- Enhanced Editor: VS Code-style editor with XP gain animations, streak toasts, and a built-in timer.

2. Deep Engagement Systems
---------------------------
- The Battle Pass: A seasonal track ("Season Zero") with Free and Premium paths unlocking exclusive skins.
- Loot Boxes: A gacha system to spend DevCoins on crates, rolling for Common, Epic, or Legendary items.
- Developer Pets: Equipable pets (AI Robot, Code Serpent) providing passive XP boosts.
- Boss Battles: Epic encounters (e.g., The Syntax Sentinel) where you answer coding questions to drain boss HP.

3. Social & Competitive Multiplayer
---------------------------
- PvP Arena: Live 1v1 matchmaking lobby with a countdown timer and live progress bars.
- Guilds: A clan system (e.g., Bug Hunters) with a leaderboard, feed, and Guild Quests.
- Friends System: Track who is Online/Offline, send requests, and challenge friends to PvP.
- Profile Pages: Showcase your equipped Avatar, Pet, RPG stats, and Badges (e.g., Week Warrior).

4. Intelligence & Progression Tools
---------------------------
- AI Mentor: Built-in chat with AI personas (The Code Sage, Algo Ninja) for hints and code reviews.
- Focus Mode: Pomodoro timer with custom intervals, ambient sounds (Lo-fi/Rain), and XP rewards.
- Analytics: Data visualization for daily XP, difficulty distribution, topic mastery, and a streak heatmap.
- Marketplace: A shop to spend DevCoins on Avatars, Pets, Titles, and XP Boosts.
- Admin Panel: Command center to track active users, system health, ban bots, and monitor pass rates.

How to run:
- Frontend: `npm run dev` in the frontend folder (Runs on http://localhost:5173)
- Backend: `python wsgi.py` in the backend folder (Runs on port 5000)
